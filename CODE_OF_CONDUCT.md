# Code of Conduct

AAASeed for Mac is an open community working on a creative-coding engine.
We want it to be a productive and welcoming place for everyone who shows
up to contribute, in good faith, regardless of background, identity, or
level of experience.

## The short version

- **Be kind and assume good intent.** Most disagreements are about
  technical trade-offs, not people.
- **Be respectful in disagreement.** Critique the code, the design,
  the doc -- not the person.
- **Be patient with newcomers.** Everyone was new to Metal, Cocoa,
  Lua, and the engine's internals at some point.
- **Be honest about scope, status, and limitations.** Hidden footguns
  and over-promised features waste other contributors' time.
- **Keep the project space focused.** Off-topic conflicts, personal
  attacks, or harassment are out of place here.

## Our standards

Behaviour we want to see :

- Welcoming, inclusive language.
- Constructive feedback, gracefully given and received.
- Empathy for other contributors, especially those new to the codebase.
- Crediting prior work : upstream engine, vendored libraries,
  prior contributors.

Behaviour we will not accept :

- Personal attacks, insults, or sustained disruption of discussion.
- Harassment of any kind, in issues, pull requests, code reviews,
  commit messages, or related channels.
- Posting other people's private information without permission.
- Any conduct that a reasonable person would find inappropriate in a
  professional, collaborative setting.

## Scope

This Code applies in all project spaces : the GitHub repository
(issues, pull requests, discussions, commit messages, review comments),
release notes, and any communication identifiably representing the
project (mailing list, chat, conference talks).

## Reporting

If you experience or witness behaviour that violates this Code, please
report it to the maintainer at **`a.mkwizu@seedexr.com`**. Reports are
handled confidentially. Include, if you can :

- A description of what happened.
- Where it happened (link to the issue / PR / comment if applicable).
- Any context that would help the maintainer assess the situation.

You will not be retaliated against for filing a report in good faith.

## Enforcement

The maintainer is responsible for clarifying and enforcing this Code.
Possible responses range, in order of severity :

1. A private clarification of the standards and a request to adjust.
2. A public correction on the affected issue / PR thread.
3. A temporary block from project spaces.
4. A permanent block from project spaces.

Decisions are at the maintainer's discretion and aim to be proportionate
to the conduct and its impact on other contributors.
